# 调用示例 v1

## 示例 1：用户直接贴一段事件文本
用户：
“分析这条新闻对跨境卖家的影响：美国讨论对部分低价进口商品征收额外费用，跨境卖家需评估成本与定价影响。”

推荐内部输入：
```json
{
  "content": "美国讨论对部分低价进口商品征收额外费用，跨境卖家需评估成本与定价影响。",
  "region_hint": "US",
  "seller_profile": {
    "platform": "amazon",
    "market": "US"
  }
}
```

## 示例 2：用户给政策摘要
用户：
“欧盟拟收紧包装与可回收要求，这事对德国站 Amazon 卖家影响大吗？”

推荐内部输入：
```json
{
  "content": "欧盟拟收紧包装与可回收要求，部分跨境卖家可能需要调整材料与标签。",
  "region_hint": "EU",
  "seller_profile": {
    "platform": "amazon",
    "market": "DE",
    "category": "home"
  }
}
```

## 示例 3：用户给 URL（后续可扩抓取）
用户：
“看看这个政策对 TikTok Shop 英国卖家有没有影响：<url>”

当前 v1 做法：
- 如果没有正文抓取链路，要求用户补一段摘要
- 或先基于用户提供的标题 / 摘要做 analyze

## 默认回答风格
优先给：
1. 是否相关
2. 主要影响维度
3. 风险等级
4. 建议动作
5. 置信度 / 不确定性

必要时再附 JSON 结构。
