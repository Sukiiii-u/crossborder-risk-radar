# Crossborder Risk Radar 信息源选择指南

MVP 阶段优先选高相关、可公开访问、更新稳定的信息源。不要一开始追求全量覆盖。

## 优先区域
- 美国
- 欧盟

## 优先主题
- 关税 / 贸易政策
- 环保 / 合规法规
- 物流异常
- 节假日 / 需求波动
- 与跨境卖家高度相关的突发新闻

## 优先来源类型
- 主流国际新闻媒体
- 官方政策 / 监管公告
- 与跨境电商强相关的行业媒体或论坛
- 平台官方公告（后续扩展）

## 选择原则
1. 先高相关，再高覆盖。
2. 先公开可访问，再考虑更复杂接入。
3. 先做美国 / 欧盟，不一开始铺全球。
4. 同类信息源优先做 2~3 个代表，不堆太多。
5. 优先能支持“风险判断 + 动作建议”的来源，而不是纯资讯噪音。

## 不要一开始做的事
- 不要追所有国家
- 不要追所有平台
- 不要追社媒全网实时流
- 不要依赖高门槛闭源源站作为 MVP 前提

## 一句话
MVP 的重点不是“抓更多新闻”，而是“抓对跨境卖家真正有用的风险信号”。
